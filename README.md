# Ontok

Ontok exists so an organization can state, once, what its work is and what that work is for, in terms every person, program, and agent shares, and then hold every result against that purpose.

## Why

Every company can buy the same software and the same models. What it cannot buy is how it does its own work and why. Today that lives in tools, settings, and people's heads, written many times and agreed nowhere. An agent cannot act safely on a purpose nobody has stated.

## The idea

Start from the end. A **Purpose** is a set of **Outcomes**, and an Outcome is a state that work produces or maintains.

An Outcome is the same thing whether it is wanted or has happened. Inside a Purpose it is intended. Inside an **Event** it occurred. That is why a result can be held against a purpose: they are one kind of thing in two places.

## Work

- **Activity.** A unit of work that turns inputs into defined outcomes.
- **Process.** Activities composed to accomplish a purpose. It has no goal attached to it. Its outcomes are its purpose.
- **Role.** A set of responsibilities. Who answers for them is a separate fact, and it can be a person, a program, or nobody yet.
- **Authority.** A formally established power to act, to decide, or to create obligations, held by someone on a stated basis.
- **Rule.** What is valid, permitted, required, or prohibited, for a stated target in a stated context.
- **Decision.** One whole case selected: the situation, the rule that applies, and what follows. There is no separate list of options to disagree with.
- **Event.** An assertion that something happened. Later work can require it.
- **Interaction.** An exchange that communicates, transfers a responsibility, or coordinates work.

Order is never drawn. Work that depends on other work requires it as an input.

## Value

**Value** is the worth of something relative to a need, an interest, or a purpose, as benefit, harm, or no change. It has eight dimensions: Economic, Time, Quality, Risk, Capability, Human Welfare, Relationships, and Resources. They are never collapsed into one number.

## Four commitments

1. **Nothing is said twice.** If two statements would have to agree, one of them is removed.
2. **A wrong combination has no form.** It is excluded by how things are built, with nothing checked afterward.
3. **Declaring is not doing, and asserting is not proving.** A defined activity has not been performed. A recorded event is a claim about the world.
4. **Identity belongs to particulars, and time belongs to the record.** A person, a program, and the thing being worked on carry identity. Definitions do not. Change is the history of what was recorded.

## What it is not

Ontok does not run anything. It is defined by these meanings and by no programming language. A data model and a semantic layer can be produced from it, and it replaces neither.

## Using it

An organization declares its own kinds by narrowing these nineteen. Begin with one flow of work, as coarse as you need, and narrow it as you learn.
