# ontok-eventcatalog

Projects an ONTOK organization into EventCatalog resources, so that an organization's declared kinds, responsibilities, occurrences, and provenance can be browsed in EventCatalog's architecture views, and its live causal graph in an ONTOK-specific layer. Planning; nothing is realized yet. The plan is `ROUGH-PLAN.md` at the repository root on this branch.

- **Import:** `ontok.eventcatalog`
- **Python:** 3.14 or later
- **Depends on:** `ontok-events`
- **Status:** planning
